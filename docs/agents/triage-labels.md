# Triage Labels

Local-markdown tracker: a label is a line in an issue file's frontmatter
(`labels: [ready-for-agent]`). The five canonical roles:

| Label | Meaning |
|---|---|
| `needs-triage` | New issue, not yet triaged |
| `needs-info` | Blocked waiting on more information from the reporter |
| `ready-for-agent` | Fully specified; an agent can pick it up |
| `ready-for-human` | Needs a human decision or work |
| `wontfix` | Accepted as-is; no action planned |
