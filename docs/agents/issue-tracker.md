# Issue Tracker

## Local markdown

Issues live as files under `.scratch/<feature>/` in this repo: one issue per
file. This is a solo project without a `gh`/GitHub CLI setup; no network
dependency. Issues are doc-sized and move between labels by editing their
frontmatter.

Uploads via engineering skills (`to-spec`, `to-tickets`, `triage`) create
files here. See `docs/agents/triage-labels.md` for the label vocabulary and
the state machine that moves issues between labels.
